# 前言

## 为什么学习 Rust？

Rust 是一门**系统级编程语言**，它同时做到了三件事：

1. **内存安全** — 没有空指针、悬垂指针、数据竞争，编译期就消灭了大部分 bug
2. **零成本抽象** — 高级语法不带来运行时开销，性能媲美 C/C++
3. **现代开发体验** — 出色的包管理器（Cargo）、友好的编译器提示、一流的工具链

Rust 自 2015 年发布 1.0 以来，连续多年在 Stack Overflow 开发者调查中被评为"最受喜爱的语言"。它被用于操作系统内核（Linux kernel）、浏览器引擎（Firefox Servo）、区块链、CLI 工具、Web 服务等各个领域。

## 什么是 Rust 2024 Edition？

Rust 的 **Edition（版次）** 机制允许语言在不破坏向后兼容性的前提下引入语法层面的改进。不同 Edition 的代码可以无缝互操作——你在 Rust 2024 项目里可以正常使用 Rust 2021 的库。

Rust 2024 Edition 于 **2025 年 2 月随 Rust 1.85.0 稳定发布**，是迄今为止规模最大的 Edition，带来了：

- 🔗 **let chains** — `if let A && let B` 链式模式匹配
- 🎯 **RPIT 生命周期自动捕获** — `impl Trait` 返回值不再需要手动写生命周期
- 🔒 **unsafe 规范化** — `extern` 块和部分属性必须显式标注 `unsafe`
- ⚡ **async 体验改进** — `Future` / `IntoFuture` 进入 prelude，async closures 稳定
- 🧹 **临时值作用域优化** — 尾表达式和 `if let` 中临时值的释放时机更合理

本书所有代码使用 **Rust 2024 Edition** 语法，要求 Rust 版本 **≥ 1.85.0**。

## 本书结构

本书分为四个阶段，循序渐进：

- **第一阶段（第 1-6 章）：基础语法** — 从零开始，建立 Rust 的核心心智模型。所有权和借用是重中之重。
- **第二阶段（第 7-11 章）：核心特性** — Trait、泛型、生命周期，Rust 最独特也最强大的部分。
- **第三阶段（第 12-16 章）：高级主题** — 并发、异步、宏，实际项目中不可或缺。
- **第四阶段（第 17-19 章）：实战补充** — 集合、测试、unsafe，填补知识空白。
- **附录** — 工具链使用、学习资源、速查表。

## 如何使用本书

1. **顺序阅读**，每章的示例代码亲手敲一遍
2. 遇到编译器报错不要怕——**Rust 的编译器错误信息是业界最友好的**，仔细阅读就能理解问题所在
3. 每章末尾有练习建议，动手实践是掌握 Rust 的最好方式
4. 本书配套代码在项目 `src/` 目录中，可随时运行验证

## 前置知识

本书假设你有基本的编程经验（知道变量、函数、循环是什么），但不需要任何系统编程或 Rust 基础。如果你有 C/C++ 背景，会对所有权和生命周期特别有共鸣；如果你来自 Java/Python/JS 背景，Rust 的一些设计理念可能需要适应时间。
