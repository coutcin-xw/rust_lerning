# Rust 2024 Edition 学习手册

> 基于 Rust 2024 Edition（≥1.85.0），从零开始系统学习 Rust 语言。

## 📖 关于本书

本书以 **Rust 2024 Edition 为默认基准**，所有代码示例直接采用 2024 Edition 语法，不做与旧版的对比。每个章节聚焦一个主题，概念讲解 + 代码示例 + 最佳实践，适合移动端阅读。

### 章节组织原则

每章按 **概念层 → 语法层 → 机制层 → 代码层 → 实践层** 的顺序组织，遵循"先理解为什么，再学怎么写，最后知道什么时候用"的认知规律：

| 层级 | 回答的问题 | 典型内容 |
|------|-----------|---------|
| **一、概念层** | 这是什么？为什么需要它？ | 问题场景、设计哲学、核心思想 |
| **二、语法层** | 怎么写？ | `$name:type` 语法、`$(...)*` 重复模式 |
| **三、机制层** | 底层如何工作？ | 编译阶段、内存布局、虚表查找 |
| **四、代码层** | 具体怎么写完整的代码？ | 从入门示例到工程级实战 |
| **五、实践层** | 怎么用好？有什么坑？ | 最佳实践、常见陷阱、工具、决策表 |
| **六、示例层** | 完整的项目级示例？ | 从头实现一个简化版标准库组件 |

> 并非每章都包含全部六层（如语法层只在宏等语法密集的章节出现），但核心原则不变：**概念先行，由浅入深**。

## 🎯 按背景选择路线

- **有其他语言经验**（C/Java/Python/Go/JS）：从[第 1 章](./01-getting-started.md)开始顺序阅读，前 6 章帮你建立 Rust 独有的心智模型
- **编程初学者**：放慢节奏，每章敲一遍代码示例，前 3 章多花时间理解所有权
- **需要快速上手项目**：精读第 2-10 章（基础+核心），然后按需查阅后续章节

## 🔧 配套代码

本书部分示例来自本项目的 `src/` 目录中的实践代码。运行方式：

```bash
cargo run    # 运行所有示例
cargo test   # 运行测试
cargo check  # 快速检查编译
```
