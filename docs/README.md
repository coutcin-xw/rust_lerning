# Rust 2024 Edition 学习手册

> 基于 Rust 2024 Edition（≥1.85.0），从零开始系统学习 Rust 语言。

## 📖 关于本书

本书以 **Rust 2024 Edition 为默认基准**，所有代码示例直接采用 2024 Edition 语法，不做与旧版的对比。每个章节聚焦一个主题，概念讲解 + 代码示例 + 最佳实践，适合移动端阅读。

## 🗺️ 学习路线

```
┌─────────────────────────────────────────────────────────┐
│  第一阶段：基础语法（第 1-6 章）                           │
│  入门必读，建立 Rust 心智模型                              │
├─────────────────────────────────────────────────────────┤
│  第二阶段：核心特性（第 7-11 章）                          │
│  Rust 的精华所在，理解后能写出地道的 Rust 代码              │
├─────────────────────────────────────────────────────────┤
│  第三阶段：高级主题（第 12-16 章）                         │
│  进阶必备，覆盖并发、异步、宏等                             │
├─────────────────────────────────────────────────────────┤
│  第四阶段：实战补充（第 17-19 章）                         │
│  标准库集合、测试、unsafe/FFI                             │
└─────────────────────────────────────────────────────────┘
```

## 🎯 按背景选择路线

- **有其他语言经验**（C/Java/Python/Go/JS）：从[第 1 章](./01-getting-started.md)开始顺序阅读，前 6 章帮你建立 Rust 独有的心智模型
- **编程初学者**：放慢节奏，每章敲一遍代码示例，前 3 章多花时间理解所有权
- **需要快速上手项目**：精读第 2-9 章（基础+核心），然后按需查阅后续章节

## 🔧 配套代码

本书部分示例来自本项目的 `src/` 目录中的实践代码。运行方式：

```bash
cargo run    # 运行所有示例
cargo test   # 运行测试
cargo check  # 快速检查编译
```
